# Configure Arduino IDE for ESP32

Download: Install the Arduino IDE (Flatpak or the .tar.xz from the official site).

Board Manager: Go to File > Preferences and paste this URL into "Additional Boards Manager URLs":
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

Install: Go to Tools > Board > Boards Manager, search for ESP32, and install the package by Espressif Systems.

Select Board: * Board: "DOIT ESP32 DEVKIT V1" (common for WROOM-32)

Port: /dev/ttyUSB0
